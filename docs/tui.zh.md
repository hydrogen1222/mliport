# TUI 参考

mliport 附带了一个基于 [Textual](https://textual.textualize.io/) 的终端用户界面（TUI）。
它是命令行界面的交互式替代方案——相同的计算，改为菜单操作而非命令行参数。

启动命令：

```bash
mliport tui
```

## 界面

TUI 由多个屏幕组成。主屏幕显示顶层菜单；按键或选择选项可导航到相应屏幕。

| 屏幕 | 功能 |
|---|---|
| **主屏幕 (Main)** | 顶层菜单——新建任务或打开高级屏幕 |
| **新建任务向导 (New Task)** | 以步骤式表单创建 sp、opt、md 或 neb 任务 |
| **运行 (Run)** | 构建并启动任意 `mliport run` 命令 |
| **分析 (Analysis)** | 浏览分析任务并配置选项 |
| **配置 (Config)** | 查看和编辑当前 settings.ini |
| **任务 (Jobs)** | 监控正在运行和已排队的计算 |

## 快捷键

| 按键 | 操作 |
|---|---|
| `q` | 退出 |
| `Esc` | 返回上一屏幕 |
| `F1` | 帮助 |
| `Enter` | 确认/激活 |
| `Tab` / `Shift+Tab` | 在字段间切换 |
| 方向键 | 在菜单和列表间导航 |

## 工作流：新建任务

1. 运行 `mliport tui`，进入**主屏幕**。
2. 选择**新建任务**——向导打开。
3. 选择计算类型（`sp`、`opt`、`md`、`neb`）。
4. 填写结构文件、模型文件/类型、输出目录及其他选项。
5. 确认生成的命令，然后按**运行**。

向导会将 INCAR 写入输出目录并启动作业。进度实时显示。**任务**屏幕列出所有正在运行和最近完成的作业。

## 工作流：分析

1. 从**主屏幕**选择**分析**。
2. 选择运行目录（包含 `trajectory/` 或 XDATCAR 的文件夹）。
3. 选择分析任务。
4. 设置选项（移动物种、温度、帧范围等）。
5. 按**运行**执行。

结果与 CLI 一样，保存在 `<run>/analysis/<task>/<analysis-id>/` 目录下。

## 与 CLI 的关系

TUI 生成并运行与手动输入相同的 `mliport` 命令。TUI 中的每个选项都对应一个 CLI 参数；CLI 参考文档记录了所有参数、默认值和边界情况。

TUI 不暴露所有参数——高级选项（自定义漂移索引、MSD 方法覆盖等）需要直接使用 CLI。

## 使用技巧

- 在远程机器上启动 TUI 之前，先从 CLI 运行 `mliport doctor` 验证安装。
- TUI 与 CLI 使用相同的 `settings.ini` 搜索路径。使用 `mliport config show` 确认当前活动的配置文件。
- 对于批处理和队列管理，CLI（`mliport batch`、`mliport queue`）比 TUI 更灵活。
